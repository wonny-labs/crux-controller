# Security policy

## Reporting a vulnerability

Report a suspected vulnerability in this repository privately. Use **Report a vulnerability** on the
repository's Security tab (GitHub private vulnerability reporting) when the tab shows it. Where it is
not shown, open an issue that asks for a private channel and carries no technical detail, and the
repository owner will answer there.

Please do not post exploit details, keys or credentials in a public issue or pull request.

A good report names the commit or release, the build step it concerns (S0, S1, S2 or later) and how
to reproduce it. There is no service level for a reply.

## What this repository is

This is a reference consumer firmware used to evaluate [Crux](https://github.com/wonny-labs/crux-pilot).
It is built in CI. Step S2 has run on a board twice, on one bench, and nothing else has. A weakness in Crux itself belongs in the `crux-pilot`
repository. A report here can be redirected there.

## Support

This repository gives no support period. Only the latest release, if one exists, is supported. There
is no release yet.
